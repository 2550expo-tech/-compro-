Gitระบบเก็บประวัติการแก้โค้ด ย้อนเวอร์ชันได้บันทึกการเปลี่ยนแปลงทุกครั้งเป็น "commit"

ติดตั้งเครื่องมือ (ทำครั้งเดียว)

  1. VS Code: ดาวน์โหลดจาก code.visualstudio.com ติดตั้งแบบค่าเริ่มต้น (Windows ติ๊ก "Add to PATH" และ "Open with Code" ไว้ด้วย)
  2. Node.js: ดาวน์โหลดรุ่น LTS (22 ขึ้นไป) จาก nodejs.org แล้วเปิด terminal พิมพ์ node -v ต้องขึ้น v22 หรือสูงกว่า
  3. Git: ดาวน์โหลดจาก git-scm.com (Mac มีมาให้แล้ว) ตรวจด้วย git --version
  4. บัญชี GitHub: สมัครที่ github.com และขอให้เจ้าของ repo เพิ่มเป็นสมาชิกถ้าต้องแก้โค้ด (อ่านอย่างเดียวไม่ต้องขอ เพราะ repo เป็นสาธารณะ)
  5. Expo Go บนมือถือ (ไม่บังคับ): ดาวน์โหลดจาก Play Store หรือ App Store

ไม่อยากติดตั้งอะไร: ใช้ VS Code บนเว็บ

มี 2 ทางที่เปิดโค้ด MindPay ด้วย VS Code ได้ทันทีในเบราว์เซอร์

  • ลิงก์ในเล่มนี้ แตะชื่อไฟล์บนหัวโค้ดก้อนไหนก็ได้ จะเปิด vscode.dev ที่ไฟล์และบรรทัดนั้น
  • จากหน้า GitHub เปิด repo บน github.com แล้วกดปุ่ม . (จุด) บนคีย์บอร์ด หน้าเว็บจะกลายเป็น VS Code (github.dev)

VS Code บนเว็บอ่านโค้ด ค้นหา (Ctrl+Shift+F) กด F12 ไปดูฟังก์ชัน และแก้ไขได้ แต่ รันคำสั่งไม่ได้ (ไม่มี terminal จึงรัน npm test หรือเปิดแอปไม่ได้) ถ้าจะรันแอปต้องโคลนลงเครื่องตามขั้นตอนด้านบน

ฝึกใช้: ตามรอย Money Runway ใน 5 นาที

  1. Ctrl+P พิมพ์ index.tsx เลือกไฟล์ใน src/app/(tabs) (หน้าหลัก)
  2. Ctrl+F ค้น useMoney แล้วกด F12 ที่คำนั้น จะเด้งไป src/data/AppProvider.tsx บรรทัด 443
  3. ที่บรรทัด 453 คลิก computeRunway แล้วกด F12 จะไปที่ src/domain/runway.ts บรรทัด 72 ซึ่งเป็นสูตรของ FR-6
  4. กด Shift+F12 ที่ชื่อฟังก์ชัน จะเห็นว่ามีเทสต์เรียกใช้ใน src/domain/__tests__/domain.test.ts ด้วย
  5. กด Alt+← สองครั้ง ย้อนกลับไปหน้าหลัก
