React Native คืออะไร

React (บท A6) เดิมใช้ทำเว็บ ซึ่งวาดหน้าจอด้วย HTML แต่แอปมือถือไม่มี HTML React Native จึงเปลี่ยน "ชิ้นส่วนพื้นฐาน" ให้เป็นของจริงบนมือถือ เราเขียน <View> แล้วบน Android กลายเป็นกล่องของ Android บน iPhone กลายเป็นกล่องของ iOS แอปจึงลื่นเหมือนแอปที่เขียนด้วยภาษาของมือถือโดยตรง

สำหรับเว็บ มีแพ็กเกจ react-native-web (บรรทัด 37 ใน package.json) แปลชิ้นส่วนเดียวกันเป็น HTML เช่น <View> → <div> <Text> → <span> โค้ดชุดเดียวจึงได้ 3 แพลตฟอร์ม

ชิ้นส่วน React Nativeคล้ายกับ (เว็บ)ใช้ทำอะไร
Viewdivกล่องสำหรับจัดวาง (การ์ด แถว คอลัมน์)
Textspan / pข้อความ (ข้อความทุกตัวต้องอยู่ใน Text)
Pressablebuttonพื้นที่ที่แตะได้ มี onPress, onPressIn, onPressOut
ScrollView / FlatList / SectionListหน้าที่เลื่อนได้เลื่อนเนื้อหายาว ๆ (FlatList/SectionList เหมาะกับรายการยาวมาก เพราะวาดเฉพาะแถวที่เห็น)
TextInputinputช่องพิมพ์ (ห่ออยู่ใน Field / AmountField ของเรา)
Imageimgรูปภาพ
SafeAreaView-ไม่ให้เนื้อหาไปซ้อนกับรอยบาก แถบสถานะ หรือขอบล่างของมือถือ
Animated.View-กล่องที่ขยับได้ (แอนิเมชัน)

การจัดวางด้วย style

React Native ไม่มีไฟล์ CSS แต่ใส่ style={{ ... }} เป็น object ตรง ๆ ชื่อเหมือน CSS แต่เป็น camelCase เช่น backgroundColor หน่วยเป็นตัวเลขเฉย ๆ (หมายถึง "จุด" ที่ปรับตามความละเอียดจอเอง) การจัดวางใช้ Flexbox:

styleความหมาย
flexDirection: 'row'เรียงลูกในแนวนอน (ค่าเริ่มต้นคือแนวตั้ง 'column')
flex: 1ขยายเต็มพื้นที่ที่เหลือ
alignItems: 'center'จัดลูกให้อยู่กลาง (แกนขวาง)
justifyContent: 'space-between'กระจายลูกให้ชิดหัวท้าย (แกนหลัก)
gap: 8ระยะห่างระหว่างลูกแต่ละตัว
padding / marginระยะห่างด้านใน / ด้านนอก
borderRadiusมุมโค้ง

ตัวอย่างจากชิ้นส่วน Row ที่ใช้ทั้งแอป: บรรทัดเดียวจบ

บรรทัด 202: สร้าง View ที่เรียงลูกแนวนอน (row) จัดกลางแนวตั้ง และเว้นระยะ gap ค่าเริ่มต้น 8 แล้วต่อด้วย style ที่ผู้เรียกส่งมา

Expo: ชุดเครื่องมือที่ทำให้ React Native ง่ายขึ้น

React Native เปล่า ๆ ต้องติดตั้ง Android Studio, Xcode และตั้งค่ามากมาย Expo ห่อทุกอย่างให้ และมีโมดูลสำเร็จรูป (expo-camera, expo-speech ฯลฯ) ที่ใช้ได้เลย สิ่งที่ Expo ให้ทีมเรา:

  • Expo Go + dev server: แก้โค้ดแล้วเห็นผลบนมือถือภายในไม่กี่วินาที
  • Expo Router: ระบบเปลี่ยนหน้าจอจากโครงสร้างไฟล์ (หัวข้อถัดไป)
  • expo export: ทำเว็บเวอร์ชันเป็นไฟล์นิ่ง ๆ เอาไปวางบนเว็บไซต์ได้
  • prebuild + EAS Build: สร้างโปรเจกต์ Android/iOS และไฟล์ APK
  • EAS Update: ส่งโค้ดใหม่ไปถึงแอปที่ลงแล้วโดยไม่ต้องลง APK ใหม่

Expo เปลี่ยนเร็วมาก ทุกเวอร์ชันมีคำสั่งที่เปลี่ยนชื่อหรือย้ายที่ ไฟล์ AGENTS.md ในโปรเจกต์จึงเตือนว่าก่อนใช้ API ของ Expo ให้เปิดเอกสารของเวอร์ชัน 57 (docs.expo.dev/versions/v57.0.0/) ไม่ใช่จำจากที่เคยเห็น

โค้ดที่ต่างกันระหว่างมือถือกับเว็บ

บางอย่างทำได้ต่างกัน เช่น มือถือเก็บข้อมูลด้วย SQLite แต่เว็บใช้ localStorage ของเบราว์เซอร์ ทีมเราแก้ด้วย ไฟล์คู่: ตั้งชื่อ storage.ts สำหรับมือถือ และ storage.web.ts สำหรับเว็บ ตอน build ระบบ (Metro bundler) เลือกไฟล์ให้เองตามแพลตฟอร์ม ที่เหลือของแอป import แค่ './storage'

ทั้งสองไฟล์มี getItem, setItem, removeItem หน้าตาเดียวกัน ฉบับเว็บห่อด้วย try/catch เพราะเบราว์เซอร์โหมดส่วนตัวอาจห้ามเก็บข้อมูล คู่ไฟล์แบบนี้มีทั้งหมด 5 คู่:

ไฟล์มือถือเว็บ
data/storageSQLite (expo-sqlite)localStorage
data/sessionStorageSetupที่เก็บการเข้าสู่ระบบของ Supabase บนมือถือของเบราว์เซอร์
services/galleryอ่านแกลเลอรีทั้งหมด (expo-media-library)ให้ผู้ใช้เลือกรูปเอง (เบราว์เซอร์ไม่อนุญาตให้เว็บเปิดแกลเลอรี)
services/speechตัวฟังเสียงของมือถือ (Google/Apple)Web Speech API ของเบราว์เซอร์

Native module แบบไม่บังคับ

บรรทัด 24 ใช้ requireOptionalNativeModule = "ขอโมดูลฟังเสียง ถ้าไม่มีก็ได้ null ไม่ต้อง crash" เพราะแอปที่ลงไว้ก่อนเพิ่มฟีเจอร์พูดจดไม่มีโมดูลนี้ แต่ยังได้รับโค้ดใหม่ผ่าน EAS Update (หัวข้อถัดไป) ถ้าเรียกแบบบังคับ แอปเก่าจะเด้งปิด แบบนี้แอปเก่าแค่แสดงช่องพิมพ์แทนไมค์

"version": "1.0.0" + "runtimeVersion": {"policy": "appVersion"}EAS Update ส่งโค้ดใหม่ให้เฉพาะแอปที่เวอร์ชันตรงกัน ถ้าเพิ่ม native module ใหม่ ต้องเพิ่มเวอร์ชัน แล้วลง APK ใหม่
"android.package"รหัสแอป com.socratesandskeletons.mindpay
"blockedPermissions"บล็อกสิทธิ์กล้อง วิดีโอ เสียงในเครื่อง ที่ไม่ได้ใช้ (ความเป็นส่วนตัว)
"plugins"ตั้งค่า native ของโมดูล เช่น ข้อความขอสิทธิ์แกลเลอรี/ไมโครโฟนเป็นภาษาไทย
"scheme": "mindpay"ลิงก์ที่ขึ้นต้นด้วย mindpay:// เปิดแอปได้ (ใช้กับลิงก์ยืนยันอีเมล)
"updates"ที่อยู่ของเซิร์ฟเวอร์ EAS Update และให้เช็กอัปเดตทุกครั้งที่เปิดแอป
"web": {"output": "single"}เว็บเป็นหน้าเดียว (single page app) ให้ JavaScript เปลี่ยนหน้าเอง

ไฟล์ app.config.js เพิ่มค่าเฉพาะตอน build เว็บ: เว็บอยู่ที่ /Socrates-and-Skeletons-/ บน GitHub Pages จึงต้องตั้ง baseUrl แต่ห้ามใส่ค่านี้ในแอปมือถือ (แอปจะหาฟอนต์และรูปผิดที่)
