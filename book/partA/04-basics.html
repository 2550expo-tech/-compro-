โปรแกรมคืออะไร

โปรแกรมคือ รายการคำสั่งที่คอมพิวเตอร์ทำตามทีละบรรทัด จากบนลงล่าง เหมือนสูตรทำอาหาร ทีมเราเขียนด้วยภาษา TypeScript ซึ่งคือภาษา JavaScript (ภาษาของเว็บ) ที่เพิ่ม "ชนิดข้อมูล" เข้าไป (บท A5) ไฟล์ที่ลงท้ายด้วย .ts เป็น TypeScript ล้วน ส่วน .tsx คือ TypeScript ที่มีโค้ดหน้าจอแบบ React ปนอยู่ (บท A6)

1. ค่า (value) และชนิดของค่า

ชนิดตัวอย่างใช้ใน MindPay
number ตัวเลข8500, -3, 0.8จำนวนเงินเป็นสตางค์ 8500 = ฿85, ความมั่นใจ 0.8 = 80%
string ข้อความ'ข้าวมันไก่', "2026-10-09"ชื่อรายการ วันที่ ข้อความบนจอ (ใส่ในเครื่องหมายคำพูด ' หรือ ")
boolean จริง/เท็จtrue, falseเข้าสู่ระบบแล้วหรือยัง, ตั้งค่าเสร็จหรือยัง (onboarded)
nullnull"ไม่มีค่า" โดยตั้งใจ เช่น รายการที่จดเองไม่มีเลขอ้างอิงสลิป (slipRef: null)
undefinedundefined"ยังไม่ได้ใส่ค่า" เช่น ไม่ได้ส่งพารามิเตอร์นั้นมา

2. ตัวแปร: กล่องที่มีชื่อ

ตัวแปรคือ "กล่องที่ติดป้ายชื่อ" ไว้ใส่ค่า เพื่อเรียกใช้ทีหลัง

const floor = 50_000; // const = ค่าคงที่ ใส่แล้วเปลี่ยนไม่ได้ let total = 0; // let = เปลี่ยนค่าได้ภายหลัง total = total + 8500; // ตอนนี้ total = 8500 const title = 'ข้าวมันไก่';
  • const ใช้บ่อยที่สุดในโค้ด MindPay เพราะค่าส่วนใหญ่ไม่ควรเปลี่ยน ใช้ let เฉพาะตอนต้องเปลี่ยนจริง ๆ
  • 50_000 คือ 50000 เครื่องหมาย _ ช่วยให้อ่านง่ายเหมือนคอมมา คอมพิวเตอร์ไม่สนใจมัน
  • ข้อความหลัง // คือ คอมเมนต์ คอมพิวเตอร์ข้าม มีไว้ให้คนอ่าน ส่วน /* ... */ และ /** ... */ เป็นคอมเมนต์หลายบรรทัด (แบบ /** VS Code จะเอาไปแสดงตอนเอาเมาส์ชี้)
  • ตั้งชื่อแบบ camelCase: คำแรกตัวเล็ก คำต่อไปขึ้นต้นตัวใหญ่ เช่น balanceSatang, averageDailyExpense ค่าคงที่สำคัญใช้ตัวใหญ่ทั้งหมด เช่น RUNWAY_CAP_DAYS

ทุกตัวแปรที่เป็นจำนวนเงิน ลงท้ายด้วย Satang เสมอ เช่น amountSatang, floorSatang เห็นชื่อแล้วรู้ทันทีว่าต้องหาร 100 ก่อนแสดงเป็นบาท กันความผิดพลาดแบบเอาบาทไปบวกกับสตางค์

4. เงื่อนไข if: ถ้า... ให้ทำ...

if (spendable <= 0) { // ทำส่วนนี้เมื่อเงื่อนไขจริง } else if (averageSatang <= 0) { // ไม่งั้น ถ้าเงื่อนไขนี้จริง ทำส่วนนี้ } else { // ไม่ตรงอะไรเลย ทำส่วนนี้ }

ในโค้ด MindPay จะเห็นรูปแบบ "เช็กกรณีพิเศษก่อน แล้วออกเลย" (early return) บ่อยมาก เช่นในสูตร Money Runway

อ่านว่า: "ถ้าเงินที่ใช้ได้ ≤ 0 ให้ส่งผลกลับเลยว่าต่ำกว่าเงินสำรอง · ถ้าค่าเฉลี่ย ≤ 0 ส่งกลับว่ายังไม่มีรายจ่าย" พอผ่าน 2 ด่านนี้ไปได้ โค้ดด้านล่างมั่นใจได้ว่าหารได้แน่นอน ไม่หารด้วยศูนย์

5. ฟังก์ชัน: เครื่องจักรรับของเข้า ส่งของออก

ฟังก์ชันคือ "ชุดคำสั่งที่ตั้งชื่อไว้" เรียกใช้ซ้ำได้ รับ พารามิเตอร์ (ของที่ส่งเข้า) และ return ผลลัพธ์ออกมา

// แบบที่ 1: function function toBaht(satang: number): number { return satang / 100; } // แบบที่ 2: arrow function (ลูกศร =>) ทำงานเหมือนกัน เขียนสั้นกว่า const toBaht2 = (satang: number) => satang / 100; toBaht(8500); // ได้ 85
  • (satang: number) = รับ 1 พารามิเตอร์ชื่อ satang ต้องเป็นตัวเลข
  • : number หลังวงเล็บ = ฟังก์ชันนี้จะคืนค่าเป็นตัวเลข
  • arrow function ที่ไม่มี { } จะ return ค่าทางขวาของ => ให้อัตโนมัติ
  • export หน้าฟังก์ชัน = ให้ไฟล์อื่น import ไปใช้ได้

ฟังก์ชันใน src/domain ทุกตัวเป็น pure function คือ (1) ใส่ค่าเดิม ได้ผลเดิมทุกครั้ง และ (2) ไม่ไปแก้อะไรข้างนอก ไม่เรียกอินเทอร์เน็ต ไม่แตะหน้าจอ เหมือนเครื่องคิดเลข จึงทดสอบง่ายมาก: ใส่ตัวเลขแล้วตรวจคำตอบ อาจารย์มักถามว่า "ทำไมแยก domain" ให้ตอบเรื่องนี้

6. Array: รายการของหลายค่า

Array คือรายการเรียงลำดับ เขียนใน [ ] คั่นด้วยคอมมา ตำแหน่งแรกคือ 0

const amounts = [12000, 0, 8500, 30000]; amounts[0]; // 12000 (ตัวแรก) amounts.length; // 4 (มีกี่ตัว) amounts.includes(0); // true

MindPay เก็บรายการเงินทั้งหมดเป็น array ชื่อ txs (ย่อจาก transactions) และใช้ "เมธอด" ของ array ต่อไปนี้ตลอด ต้องจำให้ได้

เมธอดทำอะไรตัวอย่าง
filterคัดเฉพาะตัวที่ผ่านเงื่อนไข ได้ array ใหม่ที่สั้นลงtxs.filter((t) => t.status === 'confirmed')
mapแปลงทุกตัว ได้ array ยาวเท่าเดิมtxs.map((t) => t.amountSatang)
reduceรวมทุกตัวให้เหลือค่าเดียว เช่น ผลรวมlist.reduce((s, t) => s + t.amountSatang, 0)
findหาตัวแรกที่ตรงเงื่อนไข (ไม่เจอได้ undefined)txs.find((t) => t.id === id)
someมีอย่างน้อย 1 ตัวที่ตรงไหม (true/false)list.some((t) => t.slipRef === ref)
sortเรียงลำดับdays.sort()
sliceตัดเอาบางส่วนlist.slice(0, 5) = 5 ตัวแรก

ตัว (t) => ... ที่ส่งเข้าไปในเมธอดเหล่านี้คือ arrow function ที่จะถูกเรียกกับสมาชิกทีละตัว t คือ "รายการที่กำลังดูอยู่"

ตัวอย่างจริง: ยอดคงเหลือคำนวณยังไง (FR-2)

บรรทัดความหมาย
9สร้างฟังก์ชัน confirmedOnly: รับรายการทั้งหมด คืนเฉพาะรายการที่ยืนยันแล้ว (กรองแบบร่างทิ้ง) ด้วย filter
11คอมเมนต์อธิบายสูตร: ยอดตอนนี้ = เงินตอนเริ่ม + รายรับที่ยืนยัน − รายจ่ายที่ยืนยัน
12ฟังก์ชัน computeBalance รับ 2 อย่าง: เงินตอนเริ่ม (สตางค์) และรายการทั้งหมด คืนค่าเป็นตัวเลข
13เอาเฉพาะรายการที่ยืนยันแล้ว แล้ว reduce รวมให้เหลือตัวเลขเดียว
14สำหรับแต่ละรายการ t: ถ้าเป็นรายรับ บวกเข้า (+t.amountSatang) ถ้าเป็นรายจ่าย ลบออก (-t.amountSatang) แล้วเก็บผลไว้ใน sum
15ค่าเริ่มต้นของ sum คือเงินตอนเริ่มใช้แอป

ลองคิดตาม: เริ่ม ฿3,000 (300,000 สตางค์) มีรายรับ ฿10,000 ที่ยืนยันแล้ว และรายจ่าย ฿85 กับแบบร่าง ฿200

sum เริ่ม           = 300,000
+ รายรับ 1,000,000  = 1,300,000
− รายจ่าย 8,500     = 1,291,500
(แบบร่าง 20,000 ถูกกรองทิ้งตั้งแต่บรรทัด 13)
ผล = 1,291,500 สตางค์ = ฿12,915.00

7. Object: ของ 1 ชิ้นที่มีหลายช่อง

Object คือกลุ่มของ "ชื่อช่อง: ค่า" อยู่ใน { } รายการเงิน 1 รายการใน MindPay คือ object แบบนี้

const tx = { id: 'demo-12', kind: 'expense', amountSatang: 8500, categoryKey: 'food', title: 'ข้าวมันไก่', status: 'confirmed', }; tx.title; // 'ข้าวมันไก่' (เข้าถึงช่องด้วยจุด) tx.amountSatang; // 8500

เทคนิค object ที่เจอบ่อยในโค้ด

เขียนว่าชื่อเรียกความหมาย
const { a, b } = obj;destructuring (แกะของ)ดึงช่อง a และ b ออกมาเป็นตัวแปรในบรรทัดเดียว เช่น const { balance, runway } = useMoney();
{ ...obj, status: 'confirmed' }spread (กระจาย)คัดลอกทุกช่องของ obj มาเป็น object ใหม่ แล้วเปลี่ยนเฉพาะช่อง status ของเดิมไม่ถูกแก้
[tx, ...list]spread กับ arrayarray ใหม่ที่มี tx อยู่หน้าสุด ตามด้วยของเดิมทั้งหมด (ใช้ตอนเพิ่มรายการใหม่ในบท A2)
{ kind, title }shorthandย่อจาก { kind: kind, title: title }

React (บท A6) รู้ว่าข้อมูลเปลี่ยนด้วยการดูว่า "เป็น object ตัวใหม่หรือเปล่า" ถ้าเราแก้ช่องใน object เดิมตรง ๆ React อาจไม่รู้ และหน้าจอไม่อัปเดต โค้ดจึงใช้ { ...t, status: 'confirmed' } สร้างของใหม่เสมอ (ดูตัวอย่างใน src/data/AppProvider.tsx:418)
