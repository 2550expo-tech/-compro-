Regular expression (regex) คืออะไร (ปูพื้น 2 นาที)

ทั้ง 2 ไฟล์ใช้ regex คือ "แพตเทิร์นค้นหาข้อความ" เขียนสั้น ๆ แทนการเขียน if หลายสิบบรรทัด อ่านทีละสัญลักษณ์:

\dตัวเลข 1 ตัว (0–9)
\d{1,3}ตัวเลข 1 ถึง 3 ตัว · \d{3,} = 3 ตัวขึ้นไป
+   *   ?ซ้ำ 1 ครั้งขึ้นไป · ซ้ำ 0 ครั้งขึ้นไป · มีหรือไม่มีก็ได้
( … )กลุ่มที่ "เก็บ" ผลไว้ใช้ (m[1] คือกลุ่มที่ 1) · (?: … ) กลุ่มที่ไม่เก็บ ใช้แค่จัดกลุ่ม
a|ba หรือ b
[ … ]   [^ … ]ตัวอักษรตัวใดตัวหนึ่งในวงเล็บ · ตัวที่ ไม่ใช่ ตัวในวงเล็บ
\s   \. ช่องว่าง · จุดจริง ๆ (จุดเฉย ๆ ใน regex แปลว่าตัวอะไรก็ได้)
(?! … )"ข้างหน้าต้อง ไม่ ตามด้วย …" ดูล่วงหน้าโดยไม่กินตัวอักษร
^   $   \bต้นข้อความ · ท้ายข้อความ · ขอบคำ
/…/g   /…/ug = หาทุกตัว (ไม่ใช่แค่ตัวแรก) · u = รองรับอักขระ Unicode เช่น อีโมจิ

ในไฟล์ price.ts regex ถูกเขียนเป็นข้อความธรรมดาแล้วสร้างด้วย new RegExp(…) จึงต้องเขียน \ สองตัว (\\d) ให้ได้ \ หนึ่งตัวในแพตเทิร์นจริง
