13–19import: hook ของ React · Animated (ระบบภาพเคลื่อนไหว) Easing (รูปแบบความเร่ง) · Svg · ชนิดอารมณ์และชุด · hook ลดการเคลื่อนไหว · ชิ้นภาพทั้งหมดจาก art.tsx พร้อมขนาดผืน (KLA_W, KLA_H) และจุดหมุน (PIVOT)

24–2814 รูปปาก [เปิดแค่ไหน 0–1, กี่มิลลิวินาที] ตั้งใจให้ไม่สม่ำเสมอเหมือนพยางค์จริง (ครบรอบ 1,510 มิลลิวินาที)
