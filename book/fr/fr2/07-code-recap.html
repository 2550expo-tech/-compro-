352–359เนื้อหาของหน้า key เปลี่ยนตามหน้าและรอบ (จึงเล่นแอนิเมชันใหม่ทุกครั้ง) pointerEvents="none" = การแตะทะลุไปถึงพื้นที่แตะ ยกเว้นหน้าสุดท้ายที่ต้องกดปุ่มได้ (box-none)
