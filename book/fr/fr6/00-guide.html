ภาค ข ของเล่มนี้เขียนจากมุมของฉัน คนที่รับผิดชอบ FR-6 Money Runway ทุกตัวเลขในเล่มตรวจด้วยฟังก์ชันจริงของแอปแล้ว และทุกโค้ดดึงมาจากไฟล์จริง แตะเปิดใน VS Code ได้ ถ้าเพื่อนต้องช่วยตอบคำถามเรื่อง FR-6 หรือต้องนำเสนอแทนฉัน ให้เริ่มจากบทนี้

เป้าหมาย: ตอบ 5 คำถามนี้ได้ โดยไม่ต้องเปิดเล่ม

1FR-6 ทำอะไร
แปลงยอดเงินให้เป็น "จำนวนวัน" และ "วันที่ในปฏิทิน" ว่าถ้ายังใช้เงินแบบ 7 วันที่ผ่านมา เงินจะพอถึงวันไหน เช่น "เงินพอใช้อีก 20 วัน · ถึง 28 ต.ค." (อ่าน: FR-6 ในหน้าเดียว, ปัญหาที่ฉันอยากแก้)
2สูตรคืออะไร
ปัดลง [ (ยอดคงเหลือ − เงินสำรอง − เงินในกระปุกออม) ÷ ค่าเฉลี่ยรายจ่ายต่อวัน ] แล้ววันที่ = วันนี้ + จำนวนวัน (อ่าน: วัตถุดิบ 4 อย่าง, สูตรทีละขั้น)
3ค่าเฉลี่ยคิดยังไง
รายจ่ายที่ยืนยันแล้วของวันนี้ + 6 วันก่อน (เวลาไทย) หารด้วย 7 วันในปฏิทิน นับวันที่ไม่ได้ใช้เงินด้วย ผู้ใช้ใหม่หารด้วยจำนวนวันที่ใช้แอปมาจริง (อ่าน: ค่าเฉลี่ยรายจ่ายต่อวัน)
4มีสถานะอะไรบ้าง
น้อยกว่า 7 วัน ใกล้เส้นสำรอง (critical) · 7–13 วัน เริ่มต้องระวัง (watch) · 14 วันขึ้นไป สบาย ๆ (healthy) · ยอด ≤ เส้นสำรอง ต่ำกว่าเงินสำรอง (below_floor) · ไม่มีรายจ่ายเลย ยังคำนวณไม่ได้ (no_spending) (อ่าน: สถานะ 5 แบบ และกรณีพิเศษ)
5รู้ได้ยังไงว่าถูก
unit test TC-12 ถึง TC-18 ตรวจทุกเงื่อนไข รวมขอบเกณฑ์ 6/7/14 วัน และ E2E ที่เปิดเบราว์เซอร์จริงแล้วลากแถบ ใส่ราคา และกดถามโค้ช ทั้งโปรเจกต์ผ่าน 157/157 (อ่าน: การทดสอบ FR-6)

แผนอ่าน 3 ระดับ

ระดับเวลาอ่านบทไหนผ่านเมื่อ
1 · เข้าใจภาพรวม
สำหรับเพื่อนทุกคนในกลุ่ม		30 นาทีบท A1, A2 แล้วภาค ข: FR-6 ในหน้าเดียว · ปัญหาที่ฉันอยากแก้ · สูตรทีละขั้น · ทัวร์หน้าจอ 2 บท · สคริปต์นำเสนอ 1 นาทีตอบ 5 คำถามข้างบนได้ และเปิดแอปแล้วชี้ได้ว่า Runway อยู่ตรงไหน
2 · คิดเลขเองได้
สำหรับคนที่ต้องตอบคำถามอาจารย์		2 ชั่วโมงภาค ข ตั้งแต่ต้นจนถึง "แผนที่โค้ดของ FR-6" + ทำไมฉันออกแบบแบบนี้ · ข้อจำกัด · คำถามที่อาจารย์อาจถามคิด Runway จากตัวเลขใหม่ด้วยเครื่องคิดเลขได้ถูก และอธิบายเหตุผลของ 7 วัน ปัดลง และเส้นสำรองได้
3 · อ่านโค้ดออก
สำหรับคนนำเสนอ หรืออยากเข้าใจลึก		ครึ่งวันภาค ก บท A3–A8 แล้วอ่านภาค ข ทุกบทเรียงตามลำดับ เปิด VS Code คู่กัน ลองรันเทสต์ในบท "ไล่โค้ดแบบคอมพิวเตอร์" และทำ mini-runway ในบท "สร้าง FR-6 ตั้งแต่ศูนย์"ทำแบบฝึกหัดท้ายเล่มได้โดยไม่ดูเฉลย และชี้บรรทัดในโค้ดที่ทำแต่ละกฎได้

ตัวอย่าง 2 ชุดที่ใช้ทั้งเล่ม (อย่าสับสน)

เล่มนี้ใช้ตัวเลข 2 ชุด แยกให้ออกจะอ่านง่ายขึ้นมาก:

ยอด ฿3,500 · เงินสำรอง ฿500 · ใช้เฉลี่ยวันละ ฿145 (7 วัน รวม ฿1,015)
→ ใช้ได้จริง ฿3,000 ÷ 145 = 20.69 → 20 วัน · ถึง 28 ต.ค. · สบาย ๆ
ใช้ในบทหลักการ สูตร การไล่โค้ด และสไลด์ส่วนสูตร ตัวเลขกลม ๆ คิดตามง่าย

ยอด ฿11,359 · เงินสำรอง ฿500 · ใช้เฉลี่ยวันละ ฿660
→ ใช้ได้จริง ฿10,859 ÷ 660 = 16.45 → 16 วัน · ถึง 25 ต.ค. · สบาย ๆ
ใช้ในบททัวร์หน้าจอ และสไลด์ส่วนหน้าจอ เป็นข้อมูลตัวอย่างที่แอปสร้างให้ เปิดวันอื่นตัวเลขจะต่างไป

แผนที่: สไลด์หน้าไหน อ่านเพิ่มบทไหน

ฉันทำสไลด์นำเสนอ FR-6 ไว้ 25 หน้า (วิธีใช้อยู่ในบทสุดท้าย "นำเสนอ FR-6 ด้วยสไลด์ของฉัน") ตารางนี้โยงสไลด์แต่ละหน้ากับบทที่อธิบายเรื่องเดียวกันแบบละเอียด ถ้าอยากเข้าใจสไลด์หน้าไหนลึกขึ้น ให้เปิดบทในคอลัมน์ขวา

ทริกอ่านโค้ดใน VS Code ที่ใช้บ่อยที่สุด

บท A3 และ A8 สอนวิธีใช้ VS Code ตั้งแต่ศูนย์ ส่วนนี้คือปุ่มลัด 7 ตัวที่ฉันใช้ตลอดตอนเขียน FR-6 (บน Mac ใช้ Cmd แทน Ctrl และใช้ Ctrl+− แทน Alt+←)

เปิดไฟล์จากชื่อ และไปบรรทัดที่ต้องการCtrl+Pพิมพ์ runway.ts:72 แล้ว Enter → ไปที่ computeRunway
กระโดดไปที่ฟังก์ชันถูกสร้างF12 หรือ Ctrl+คลิกคลิกที่ bkkDayKey ในบรรทัด 37 → เปิด dates.ts ให้เลย

ดูว่าใครเรียกฟังก์ชันนี้บ้างShift+F12วางเคอร์เซอร์ที่ computeRunway → เห็นว่าในแอปถูกเรียกที่ AppProvider จุดเดียว นอกนั้นคือใน runway.ts เอง (เช็กก่อนจ่าย ลองปรับ) และในไฟล์เทสต์
ดูชนิดข้อมูลเอาเมาส์ชี้ค้างชี้ที่ days → เห็น number | null

ลิงก์ "เปิดใน VS Code (เว็บ)" ใต้โค้ดทุกก้อนเปิดได้ทันทีโดยไม่ต้องติดตั้งอะไร เหมาะกับการอ่าน ปุ่ม Ctrl+P, Ctrl+Shift+F และการชี้ดูใช้ได้ แต่การกระโดดข้ามไฟล์ (F12) และการรันคำสั่ง (Terminal) ต้องใช้ VS Code ในเครื่องที่โคลนโปรเจกต์แล้ว (บท A3)

วิธีอ่านแต่ละบทให้ได้ผล

  1. อ่านหัวบทและประโยคใต้หัวบทก่อน จะรู้ว่าบทนี้ตอบคำถามอะไร
  2. คิดตัวอย่างตามด้วยเครื่องคิดเลข ทุกครั้งที่เห็นตัวเลข ถ้าคิดแล้วไม่ตรง ให้หยุดหาว่าพลาดตรงไหน ตรงนั้นคือจุดที่ยังไม่เข้าใจ
  3. อ่านโค้ดคู่กับตาราง "อ่านทีละบรรทัด" อ่านบรรทัดในโค้ดก่อน เดาความหมายเอง แล้วค่อยดูคำอธิบาย
  4. เล่าให้คนอื่นฟัง ถ้าอธิบายให้เพื่อนที่ไม่ได้เรียนเรื่องนี้เข้าใจได้ภายใน 1 นาที แปลว่าเข้าใจจริง
