# หนังสือคู่มือศึกษา MindPay (FR-1 ถึง FR-6)

หนังสือ PDF สำหรับให้สมาชิกกลุ่ม 13 Socrates and Skeletons (วิชา 15031001 Introduction to Software Engineering) ศึกษาระบบ MindPay ทีละ FR
ทุกเล่มมี 2 ภาค:

- **ภาค ก · พื้นฐานทั้งระบบ** (เหมือนกันทุกเล่ม) เครื่องมือ, TypeScript, React, Expo (เว็บ + แอปจากโค้ดชุดเดียว), Supabase, การเชื่อม AI, UX/UI, การทดสอบ, Git/GitHub
- **ภาค ข · FR ของเล่มนั้น** ปัญหา, Requirement, หน้าจอจริง, หลักการ, ตัวอย่างคิดมือที่ตรวจด้วยฟังก์ชันจริง, โค้ดจริงพร้อมคำอธิบายทีละบรรทัด, การทดสอบ, เหตุผลการออกแบบ, ข้อจำกัด, คำถามอาจารย์, แบบฝึกหัด และสคริปต์นำเสนอ

โค้ดทุกก้อนในเล่มดึงจากโปรเจกต์จริงที่ commit `646b485` และแตะเปิดใน VS Code (vscode.dev) หรือ GitHub ได้ตรงบรรทัด

## โครงสร้างต้นฉบับหนังสือ (โฟลเดอร์ `book/`)

```
book/
  build.mjs     สร้าง PDF: ประกอบปก + สารบัญ + ภาค ก + ภาค ข แล้วพิมพ์ด้วย Chromium
  style.css     หน้าตาของเล่ม (ฟอนต์ Anuphan / Noto Serif Thai)
  howto.html    หน้า "วิธีใช้เล่มนี้"
  partA/        ภาค ก (14 บท ใช้ร่วมกันทุกเล่ม)
  fr/fr1 … fr6  ภาค ข ของแต่ละเล่ม
  shots/ e2e/   ภาพหน้าจอจากเว็บเวอร์ชันจริง (โหมดทดลอง และบัญชีทดสอบกับเซิร์ฟเวอร์จำลอง)
  img/ fonts/   รูปน้องกล้า และฟอนต์ที่ฝังในเล่ม
  scripts/      สคริปต์ถ่ายภาพหน้าจอ (รันจากโฟลเดอร์ scripts ของโปรเจกต์ MindPay เพราะใช้ e2e/fake-backend.mjs)
```

แท็กพิเศษในไฟล์ HTML: `<x-ch>` บท · `<x-code src lines>` โค้ดจริงพร้อมเลขบรรทัดและลิงก์ VS Code · `<x-snip>` ตัวอย่างโค้ดที่ไม่ได้มาจากโปรเจกต์ · `<x-box kind>` กล่องสี · `<x-fig>` ภาพมือถือ · `<code>src/…</code>` กลายเป็นลิงก์เปิดไฟล์

## สร้าง PDF ใหม่

1. โคลนโปรเจกต์ MindPay (`2550expo-tech/Socrates-and-Skeletons-`) แล้ว `git checkout 646b485` และ `npm install` (ต้องมี Playwright กับ Chromium)
2. แก้ค่า `REPO` บรรทัดบนของ `book/build.mjs` ให้ชี้โฟลเดอร์ที่โคลนไว้
3. ต้องมี `pdftotext` / `pdfinfo` (poppler-utils) และ Python ที่มี `pypdf`
4. รัน `node book/build.mjs fr6` (หรือ `fr1 … fr6` หลายเล่มพร้อมกัน) ได้ไฟล์ใน `book/out/`
